# Employee Shift-Swap System

## Project Overview

This repository contains the Milestone 1 documentation and future capstone project files for the Employee Shift-Swap System in MIS 3371-26242.

## Project Purpose

The project will provide employees with an organized way to request shift swaps, obtain the required approvals, and track the status of each request.

## Main Transaction

An employee submits a request to swap an assigned shift with another qualified employee.
